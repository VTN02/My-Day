# MyDay — MVP Scope Specification

## Core Features (Milestone 0 - 9)
1. **Today Dashboard**:
   - Personalized greeting, daily task progress, overdue tasks, today's income/expenses, cash & card balances, recent notes.
2. **Task Management**:
   - Create, edit, complete, delete tasks with priority (Low, Medium, High), categories, due date/time, and local notifications.
3. **Monthly Calendar**:
   - Month view with task density indicators, day selection, task breakdown for selected day.
4. **Finance Tracking**:
   - Dual account system (Cash and Card).
   - Income and Expense tracking in integer minor units.
   - 4 tabs: Overview, Plan (budgets), Analytics, Compare (month-over-month).
5. **Notes & Attachments**:
   - Rich notes with categories, local file attachments (images, PDFs, documents) stored in app storage.
6. **Profile & Settings**:
   - Local profile (display name, bio, photo).
   - Language switching (English, Tamil, Sinhala).
   - Currency configuration (Default: LKR).
   - Dark/Light theme mode.
   - WhatsApp Tech Community external link.
